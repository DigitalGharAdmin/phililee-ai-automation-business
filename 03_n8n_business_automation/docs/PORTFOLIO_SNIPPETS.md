# Ready-to-use portfolio descriptions

## GitHub short description

Configurable n8n inquiry automation with Sheets tracking, controlled Gmail
acknowledgements, optional AI, duplicate protection and reconciliation states.

## GitHub README introduction

A reusable business-inquiry workflow built with n8n. It validates intake, applies
deterministic routing, records request state and permits acknowledgements only when
policy and persistence checks pass. Client configs generate sanitized workflow pairs;
live credentials stay external. Includes offline tests and operator-reported acceptance.

## Upwork portfolio

Built a configurable n8n system for sales and support intake, spreadsheet tracking
and approved receipt emails. The implementation handles duplicates, logging failures
and uncertain delivery with explicit recovery states. Two client demos demonstrate
custom routing and email content using one core workflow. Includes validation,
sanitized acceptance evidence and client onboarding documentation. Production setup
and operator reconciliation remain client-specific responsibilities.

## Fiverr portfolio paragraph

Reusable n8n business automation for inquiry validation, routing, Google Sheets
tracking and optional Gmail acknowledgements. Customize business identity, routes
and wording through validated settings. Duplicate protection and safe failure paths
support predictable operation; credentials are configured privately during onboarding.

## LinkedIn project description

Developed an n8n business automation demo with client-configurable routing, optional
AI assistance and controlled email acknowledgement. Reliability work includes
bounded retries, duplicate guards, privacy-safe alerts and manual reconciliation
for ambiguous outcomes. Backed by offline regression tests and documented live
acceptance for the core, reliability and customization layers.

These descriptions do not claim measured ROI, guaranteed accuracy, zero downtime
